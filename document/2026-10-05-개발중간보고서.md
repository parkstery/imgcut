## 2. 현재까지 완료된 기능

### 2.1 핵심 편집

- 레이어 기반 캔버스 (이미지·도형·텍스트·브러시)
- 선택 / 이동 / 리사이즈 / 회전
- 도형 도구 (사각형, 원, 선, 폴리라인, 호 등)
- 텍스트 도구 (기본 12px, Ctrl+Enter 확정)
- 스포이드·채우기·크롭 도구

### 2.2 이미지 크롭·오려내기

- 그림 자르기 (이미지 단위): 남기기 / 복사 / 오려내기
- 화면 영역 크롭 (툴바 Crop): Ctrl+C 캡처, Ctrl+X 오려내기, Enter 캔버스 크기 적용
- 크롭 조각 붙여넣기 시 원본 기준 **우하향 +10px** 위치
- 원형 크롭을 빼는 과정에서 자르기 영역이 이미지 전체로 되돌아가던 문제 수정 (`f4829d3`). 지정한 사각형이 유지됨

### 2.3 선택·붙여넣기 UX

- 드래그 박스 선택: **사각형 안에 완전히 포함된 개체만** 선택 (걸친 개체 제외)
- 복사/복제/붙여넣기 오프셋: 가로·세로 각 **10px**
- 앱 내부 클립보드 우선 (크롭 PNG가 OS 클립보드에 있어도 위치 유지)

### 2.4 UI·패널

- 레이어 패널: 헤더에서만 레이어/개체 상하 이동, 기본명 `레이어1`
- 속성 패널: 필터·크롭·XYWH 압축, 이미지 비율 잠금(`lockAspectRatio`)
- 내보내기: PNG 기본, 파일명 `im-YYMMDD-HHMMSS` 형식. 버튼은 **클립보드 붙여넣기** 바로 오른쪽
- 도구 모드 유지 (사용 후 도구 전환하지 않음)
- 새로 만들기: 크기·배경을 고른 뒤 생성하면 기존 개체를 모두 지우고 빈 `레이어1`만 연다. 실행 취소로 이전 개체가 돌아오지 않도록 이력도 초기화 (`f4829d3`)
- 화면 배치 (`c51dd94`): 헤더·도구 막대 컨트롤은 왼쪽에 두고, 오른쪽 속성 패널은 창 맨 위까지 이어진다. 창 높이가 부족하면 속성 패널만 세로 스크롤된다

### 2.5 기타

- 도형 기본 스타일: 선 빨강, 채우기 투명
- Vercel 배포 이력 있음 (별도 환경: `imgman-mu.vercel.app` 등)

## 7. 결론

편집기 핵심 흐름(선택·그리기·크롭·붙여넣기·내보내기·레이어)은 동작 가능한 중간 단계에 도달했다.  
원형 크롭은 철회된 상태이고, 그 과정에서 깨졌던 사각형 그림 자르기는 복구했다.  
새 캔버스는 이전 개체를 남기지 않으며, 속성 패널은 창 높이에 맞춰 스크롤된다. 이후 기능은 요구사항에 맞춰 단계적으로 추가하면 된다.
